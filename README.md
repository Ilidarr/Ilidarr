# Дневник тренировок

## Модуль 1. Справочник упражнений

*   Я, как пользователь, хочу иметь возможность создавать списки упражнений и отслеживать их. 
*   Файлы: Exercise / CatalogService

## Модуль 2. Журнал тренировочной сессии

*   Я, как пользователь, хочу иметь возможность, просматривать инструкции к упражнения для правильного их выполнения. 
*   Файлы: Workout / SetEntry

## Модуль 3. Анализ прогресса и Рекордов

*   Я, как пользователь, хочу видеть свой личный рекорд в каждом упражнении для того чтобы стремиться превзойти себя
*   Файлы: ProgressAnalytics

## Модуль 4. Профиль пользователя и Сохранение данных

*   Я, как пользователь, хочу иметь свой профиль для того чтобы другие могли видеть мой прогресс и показывать его другим
*   Файлы: UserProfile / WorkoutStorage
